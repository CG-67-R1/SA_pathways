# SA motorcycle pathway briefing

A plain-language website you can host for free on GitHub. No technical install. No database.

The site is the files in this folder: ordinary web pages. Anyone can open `index.html` on a computer, or you can put the folder on GitHub Pages so people get a normal web address.

## What to upload

Upload **everything in this folder** to the **root** of a new GitHub repository — not inside a second folder called `public-site`.

You should see `index.html`, `css`, `js`, and the other `.html` pages at the top of the repo.

## Put it on GitHub Pages (click path, no code)

1. Sign in at [github.com](https://github.com) and click **New repository**.
2. Name it something like `sa-motorcycle-pathway`. Make it **Public**. Do not add a README (you already have one). Create it.
3. On the empty repo page, click **uploading an existing file**.
4. Drag every file and folder from this `public-site` folder onto the page. Commit.
5. Click **Settings**, then **Pages** (left menu).
6. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
7. Branch: **main** (or **master**). Folder: **/ (root)**. Save.
8. Wait one or two minutes. Refresh the Pages settings. GitHub will show an address like:

   `https://YOUR-USERNAME.github.io/sa-motorcycle-pathway/`

9. Share that address. It works on phones.

If the site shows a 404, wait another minute, then confirm `index.html` is in the repo root, not in a subfolder.

## Open it on your computer without GitHub

Double-click `index.html`, or (better) drag that file into a browser window. The menu and other pages will work.

## What this site is

Independent briefing, 1 October 2026. Not a government website. Please do not contact landowners, council or ministers unless the project lead has asked you to.
